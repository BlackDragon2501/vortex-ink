# Vórtex Ink

Vórtex Ink, de Vortex Company: dibuja tu firma o sello con lápiz sensible a presión, quita el fondo blanco automáticamente, guárdalo en tu galería local y colócalo sobre PDFs en la posición que quieras. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
